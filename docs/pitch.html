The system

A swarm of agents that does the whole job —
not another dashboard that watches it fail.

Sentinel

Watches request logs, auth signals, rates. Raises structured incidents to an append-only event bus — the audit log.

Triage

Classifies SQLi / brute-force / scan / DoS / CVE-probe. Scores severity. Dedupes noise.

Containment

Reversible defense inside policy — block IPs, rate-limit, isolate — autonomously. Seconds, not tickets.

Patch ★

A Devin session traces the exploit to the vulnerable line, writes the fix, opens a real PR, proves the re-fired attack fails.

Self-heal

Watches the platform itself — crashed service, bad deploy, config fault → diagnose, repair, verify.

Comms

Calls the human by phone only when policy requires approval. Transcript lands in the audit log.

Bounded autonomy: observe & contain → autonomous · deploy & high-impact → phone-approved · offensive action → prohibited.
